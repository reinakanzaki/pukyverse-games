PORTAL-002

外部配布データへの
社内ファイル混入について

外部向けに公開したデザイン制作資料へ、 社内利用を想定したファイルが含まれていた事象について、 以下のとおり報告します。

発生日
2026年7月15日
確認日
2026年7月16日
対象資料
デザイン制作ガイドライン Version 4.2
担当部署
制作管理部
対応状況
対応中

OVERVIEW

事象の概要

2026年7月15日に外部公開した 「デザイン制作ガイドライン Version 4.2」の ダウンロードデータ内に、社内作業用として管理していた フォルダの一部が含まれていたことを確認しました。

該当データは、オリジナルコントローラー制作を希望する お客様向けに公開したもので、入稿用テンプレート、 ロゴデータ、カラーパレット等をまとめたZIP形式の資料です。

本来は外部配布対象のファイルのみを専用フォルダへ移し、 そのフォルダを圧縮する運用となっていますが、 今回は作業用フォルダ全体がそのまま圧縮されていました。

INCLUDED FILES

混入が確認されたデータ

Brand_Guideline_v4_FINAL.zip

  • README.txt
  • Controller_Template.png
  • Logo/
  • Internal/
    • NOTICE.txt
    • Portal.url

混入していたファイルには、社内ポータルへの接続情報を含む インターネットショートカットが含まれていました。

現時点で、当該ショートカットを経由した外部アクセスの有無は 確認できていません。

CAUSE

発生原因

01

作業用フォルダの直接圧縮

公開用データを別フォルダへ移動せず、 制作作業に使用していたフォルダを そのまま圧縮していました。

02

公開前確認の不足

ダウンロードデータの内容確認が、 ファイル名と容量の確認のみで完了していました。

03

担当者への引き継ぎ不足

新任担当者に対して、 配布用ファイル作成時の確認手順が 十分に共有されていませんでした。

PREVIOUS CASE

過去の類似事象

前回のデザインテンプレート更新時にも、 作業メモおよび社内確認用画像が 外部配布データへ含まれる事象が発生していました。

前回事象では社内システムへの接続情報は含まれておらず、 配布開始から約30分後にデータを差し替えています。

管理部門からの確認事項

前回対応時に定めた公開前確認手順が、 制作管理部内で継続して運用されていなかったことが 確認されています。

RESPONSE

現在の対応

  1. 01

    配布データの差し替え

    社内向けファイルを除外した修正版データを作成し、 公開データの差し替えを進めています。

  2. 02

    ポータル接続情報の確認

    混入したショートカットに記載されていた 接続先とアクセスログを確認しています。

  3. 03

    公開手順の再周知

    配布用ファイルの作成と公開前確認を 複数名で実施するよう、手順を変更します。

PREVENTION

再発防止策

項目 対応内容 担当 期限
公開用フォルダの分離 外部配布用の専用フォルダを作成し、 作業フォルダから直接圧縮しない。 制作管理部 即日
ダブルチェック 公開前に担当者と確認者の 2名でZIP内の全ファイルを確認する。 制作管理部 2026.07.18
アクセス情報の管理 社内システムへのショートカットを 制作データと同一階層へ保存しない。 システム管理部 2026.07.20
新人研修の追加 公開データ作成に関する確認項目を 新任担当者向け研修へ追加する。 人事総務部 2026.07.31

COMMENT

担当部署からの報告

公開作業を担当した社員が、 配布用資料と作業中の社内資料を 同一フォルダ内で管理していました。

担当者は入社後間もなく、 今回が初めての外部公開作業でしたが、 確認を担当する社員を配置していなかった点を含め、 部署全体の管理上の問題と認識しています。

今後は担当者個人へ確認を任せず、 公開前に必ず上長の確認を行います。
